# PostgreSQL Catalog HTTP Routes Module (বাংলা)

এই ডকুমেন্টটি `apps/api/src/postgres-catalog-routes.mjs` মডিউলের আর্কিটেকচার, পাবলিক এন্ডপয়েন্ট, নিরাপত্তা সীমা এবং টেস্ট যাচাইকরণ বিস্তারিত বর্ণনা করে।

## পটভূমি ও উদ্দেশ্য

PR #3-এর মূল সীমাবদ্ধতা ছিল synchronous SQLite রুটগুলোর সাথে async PostgreSQL অ্যাডাপ্টারের স্বাতন্ত্র্য এবং route-by-route মাইগ্রেশনের প্রয়োজনীয়তা। Issue #47 অনুযায়ী, ক্যাটালগ ডোমেনের জন্য একটি সম্পূর্ণ বিচ্ছিন্ন HTTP রুট হ্যান্ডলার তৈরি করা হয়েছে যা:
- কোনোভাবে SQLite `core.mjs` বা `routes_public.mjs` বা `node:sqlite`-এর ওপর নির্ভর করে না।
- কমার্স/চেকআউট বা অথ মডিউলের কোডের সাথে ওভারল্যাপ হয় না।
- HTTP বাউন্ডারিতে কুয়েরি প্যারামিটার স্যানিটাইজেশন এবং রেঞ্জ সীমাবদ্ধতা প্রয়োগ করে।

## এক্সপোজড পাবলিক রুটসমূহ

1. **ক্যাটাগরি তালিকা**: `GET /api/v1/categories`
   - সকল ক্যাটাগরি বাংলা নামের ক্রমানুসারে রিটার্ন করে (`ORDER BY name_bn`)।
2. **ব্র্যান্ড তালিকা**: `GET /api/v1/brands`
   - সকল অনুমোদিত ব্র্যান্ড নামের ক্রমানুসারে রিটার্ন করে (`ORDER BY name`)।
3. **পণ্য তালিকা ও ফিল্টারিং**: `GET /api/v1/products`
   - কুয়েরি প্যারামিটার: `q` (সর্বোচ্চ ৮০ অক্ষর), `category` (সর্বোচ্চ ১০০ অক্ষর), `brand` (সর্বোচ্চ ১০০ অক্ষর), `min_price`, `max_price`, `sort` (`price_asc`, `price_desc`, `newest`), `limit` (১ থেকে ১০০ এর মধ্যে ক্যাপড, ডিফল্ট ১০০), `offset` (০ থেকে ১০,০০০ এর মধ্যে ক্যাপড, ডিফল্ট ০, যা deep-offset denial-of-service প্রতিরোধ করে)।
   - ব্যবহারকারীর ইনপুটের ওপর সরাসরি SQL ইন্টারপোলেশন নেই; সম্পূর্ণ প্যারামিটারাইজড কুয়েরি ও হোয়াইটলিস্টেড সর্টিং।
4. **সার্চ সাজেশন**: `GET /api/v1/products/suggest`
   - `q` প্যারামিটার সর্বোচ্চ ৪০ অক্ষরে সীমিত। ফাঁকা কুয়েরিতে ডাটাবেজে হিট না করে সাথে সাথে খালি অ্যারে রিটার্ন করে। সর্বোচ্চ ৮টি সাজেশন রিটার্ন হয়।
5. **পণ্যের বিস্তারিত বিবরণ**: `GET /api/v1/products/:id`
   - অনুমোদিত বিক্রেতা এবং সক্রিয় পণ্য শুধুমাত্র প্রদর্শিত হয় (`p.active=1 AND p.status='ACTIVE' AND sp.status='APPROVED'`)।
   - অনুপস্থিত পণ্যে ৪0৪ এরর ফেরত পাঠানো হয়।
   - বিক্রেতার সংবেদনশীল তথ্য (`seller_id`, `password`) পাবলিক আউটপুট থেকে সম্পূর্ণ বাদ থাকে।
6. **পণ্যের রিভিউ তালিকা**: `GET /api/v1/products/:id/reviews`
   - পণ্যের সাম্প্রতিক রিভিউ ও রেটিং প্রকাশ করে।

## নিরাপত্তা ও সীমাবদ্ধতা

- **SQLite Isolation**: মডিউলটি বিশুদ্ধ ES Module এবং এতে কোনো SQLite নির্ভরতা নেই।
- **Production Guard**: প্রোডাকশনে ডাটাবেজ কনফিগারেশন অনুপস্থিত থাকলে সিস্টেম fail-closed থাকবে।
- **Live Database Gate**: লাইভ পোস্টগ্রেস যাচাইকরণের জন্য `POSTGRES_TEST_DATABASE_URL` প্রয়োজন; এটি সেট না থাকলে লাইভ টেস্ট স্কিপ হিসেবে চিহ্নিত হয় এবং পাস হিসেবে গণনা করা হয় না।
